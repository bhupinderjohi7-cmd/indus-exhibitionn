INDUS VALLEY EXHIBITION - LOCAL PRESENTATIONS

Easiest (one device): double-click any .html file, or index.html. Works without internet.

For visitors to scan QR codes with their phones:
1. Install Python from python.org if you do not have it (tick "Add Python to PATH").
2. Put this folder on the laptop you will use at the exhibition.
3. Connect the laptop and the visitors' phones to the SAME Wi-Fi (a phone hotspot is fine).
4. Double-click start-server.bat (Mac/Linux: ./start-server.sh). Leave the window open.
5. Find the laptop's IP address (Windows: open Command Prompt, type ipconfig, look for IPv4 Address).
6. Open qr-local.html, type the IP, press Make QR codes, download or print them. This step needs internet once.
7. Test with a phone on the same Wi-Fi.

Note: the QR codes only work while the laptop is on, the server is running and the phone is on the same network.
The References slide links need internet.

PUBLISH ON YOUR OWN FREE WEBSITE (no Claude, visitors need nothing installed):
Netlify: go to app.netlify.com/drop, create a free account, drag this whole unzipped folder onto the page. You get an address like https://something.netlify.app
Then open qr-web.html, type that address, press Make QR codes, and print them. Test on a phone.
